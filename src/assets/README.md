# 网页生产素材

`src/assets` 按网站章节归类，网页实际引用的压缩版素材放在对应模块目录；原始高码率素材继续保留在 `素材归档`。

## 目录对应关系

| 网站模块 | 生产素材目录 |
| --- | --- |
| 01 AI 短剧 | `01-ai-drama/videos`、`01-ai-drama/covers` |
| 02 AI 图片 | `02-ai-images/gallery` |
| 03 Coze 工作流 | `03-workflow/videos`、`03-workflow/covers` |
| 04 自制 Skill | `04-skills/script-image-search`、`04-skills/github-skill-cn-import` |
| 能力地图 | `capability-map/obsidian-relationship-graph.png` |
| 05 视频生成平台 | `05-video-platform/videos`、`05-video-platform/covers` |
| 06 游戏作品 | `06-games/videos`、`06-games/covers` |

## Skill 素材规则

- `script-image-search`：图片、演示视频和 ZIP 下载包。
- `github-skill-cn-import`：图片和 ZIP 下载包，按要求不接入网页视频。

替换素材时，先放入对应的 `素材投放目录` 模块，确认后再生成网页版本，并更新对应的生产素材目录。
